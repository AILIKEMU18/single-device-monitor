\# 单设备传感器数据监控平台

> Python + MySQL + Flask 后端项目



\## 项目功能

1\. 模拟传感器采集温度、压力数据，写入MySQL数据库

2\. 统计温度最大值、最小值、平均值

3\. 筛选异常状态数据

4\. 提供Flask接口，支持查询统计结果、导出全部数据/异常数据CSV文件

5\. CSV导出编码兼容Windows，可直接用Excel打开



\## 技术栈

\- Python

\- MySQL

\- Flask（Web接口）

\- Git 版本管理
